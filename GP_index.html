About Our Project

WordDAL is a simple dictionary web application designed to help users quickly understand English words.

Users can search for a word and view useful information such as its definition, pronunciation, part of speech, and example sentences.

Our application uses the Free Dictionary API to retrieve dictionary information from an online source.
