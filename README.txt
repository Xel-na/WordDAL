APIs USED:

1. Wiktionary REST API
   Purpose: Retrieves English word definitions, parts of speech, and available example sentences.
   Documentation/Website: https://en.wiktionary.org/

   API Endpoint:
   https://en.wiktionary.org/api/rest_v1/page/definition/{word}

2. Datamuse API
   Purpose: Retrieves synonyms, antonyms, and autocomplete suggestions.
   Documentation: https://www.datamuse.com/api/

3. Web Speech API
   Purpose: Reads the searched word aloud using the browser's built-in speech synthesis.
   Documentation: https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API

INSTRUCTIONS TO RUN THE APPLICATION:

1. Download or clone the WordDAL project folder.
2. Open the folder in Visual Studio Code.
3. Make sure these files and folders are present:
   - index.html
   - APP.html
   - Style.css
   - Script1.js
   - Asset folder containing the team member images
4. Open index.html using a web browser or Visual Studio Code Live Server.
5. Click "Open Dictionary App" to open the dictionary.
6. Enter an English word and click "Search."
7. View the definition, examples, synonyms, and antonyms.
8. Click "Hear Pronunciation" to listen to the word.

SPECIAL INSTRUCTIONS:

- An internet connection is required to retrieve information from Wiktionary and Datamuse.
- Use a modern browser such as Google Chrome,Brave or Microsoft Edge.
- No API key is required for the APIs used by this project.
- Pronunciation depends on the speech voices available on the user's browser and device.
- Keep the HTML, CSS, JavaScript, and Asset folder in their correct locations so the application works properly.

PROJECT DESCRIPTION:

WordDAL is a dictionary web application that helps users understand English words through definitions, parts of speech, example sentences, synonyms, antonyms, autocomplete suggestions, and pronunciation.
